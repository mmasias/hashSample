# Hash propuesto

El hash propuesto hace lo siguiente:

- Toma la primera letra de cada nombre de alumno
- Toma la primera letra de cada apellido de alumno
- Toma el último carácter de cada DNI
- Concatena las notas finales redondeadas
- Agrega un "1" por cada alumno aprobado y un "0" por cada suspenso
- Añade el código de la asignatura
- Añade la primera letra del nombre de la asignatura
- Añade el número de créditos
- Añade el año y mes de la fecha

Finalmente, realiza un cifrado simple desplazando cada carácter 3 posiciones en la tabla ASCII.
